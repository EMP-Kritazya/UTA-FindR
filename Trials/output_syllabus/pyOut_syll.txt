Course Description 
Course Title: Database Systems and File Structures 
This is a first course in databases. The course covers the relational data model and its query 
languages, database design, transactions, database security, and performance. The course will 
also introduce database system internals and file/index data structures. 
Prerequisites: C or better in each of the following: CSE 1325 and CSE 3318

Student Learning Outcomes 
By the end of this course, you will be able to: 
1. Querying: Given a relational database schema and the specification of a query in 
English, students will be able to compose correct queries in relational algebra or SQL 
(Structured Query Language) to retrieve the data the meets the query specification. 
2. Database Design: Given the description of a database in English, students will be able 
to draw an ERD (Entity-Relationship Diagram) that correctly models the database and 
translate the ERD to CREATE TABLE statements in SQL. 
3. Functional Dependencies and Normalization: Students will be able to describe the 
role of functional dependencies in maintaining database integrity and correctly use 
functional dependencies to change a database schema to Boyce-Codd Normal Form. 
4. Programming: Students will be able to write programs that connect to a database 
system and effectively modify or retrieve data in a database managed by this system. 
5. Transactions: Students will be able to accurately describe the guarantees offered by 
database systems to user transactions and identify the effect of these guarantees on 
their programs.

Generative AI Use in This Course 
The use of Generative AI (GenAI) in course assignments and assessments must align with the 
guidelines established by the instructor. Unauthorized use of GenAI could result in breaches of 
academic integrity. Instructors are responsible for clearly delineating the permissible uses of 
GenAI in their courses, underscoring the importance of responsible and ethical application of 
these tools. 
Community Standards within the Office of the Dean of Students articulate the university's stance 
on academic integrity and scholastic dishonesty. These standards extend to the use of GenAI. 
Unauthorized or unapproved use of GenAI in academic work falls within the scope of these 
policies and will be subject to the same disciplinary procedures.  
As the instructor for this course, I have adopted the following policy on student use of GenAI. 
Students may use GenAI tools freely to assist in understanding course content and creating 
homework solutions. It is expected that students will engage with these tools ethically and 
responsibly, ensuring that their use of GenAI contributes to a deeper understanding of the 
subject matter and the development of relevant competencies. Students are reminded that 
GenAI is not available in exams, which constitute the bulk of the grade in this course.
